1: Challenger

About the project

Challenger is a production mobile application for finding other people and organizing sports activities.

  • Events and invitations
  • Map overview of activities and sports facilities
  • Real-time chat
  • User profiles
  • Internal administration and analytics dashboard

It was built as part of my bachelor's project. The first production version was developed in around 1.5 months.

My work covered backend architecture and APIs, PostgreSQL data modelling, real-time WebSocket communication, deployment and infrastructure, the internal administration platform, and parts of the React Native application.

Challenger was co-developed with Daniel Lorenzen.

Tech stack

  • Go
  • PostgreSQL
  • React Native
  • WebSockets

2: Haddle

About the project

Haddle is a local-first messenger application intended for both desktop and mobile use. Messages are encrypted and stored locally rather than centrally. A relay server mainly forwards communication between clients without permanently storing message data.

  • Friend requests via QR codes
  • Real-time communication through a non-persistent relay server

The project involved working through real-time communication, local storage, synchronization, identity, and communication between peers.

View Haddle on GitHub.

Tech stack

  • Go
  • Flutter
